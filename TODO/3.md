==================================================
1. Frame Buffer Pooling
==================================================

Reduce per-frame memory allocations.

Current design already uses:

    Value::Frame(Arc<Frame>)

which solves ownership and sharing.

However, check whether every operation creates new pixel buffers every
frame.

If operations repeatedly allocate:

    Vec<u8>
    Image buffers
    Mask buffers
    Frame buffers

introduce reusable buffer allocation.

Implement:

    FramePool

owned by:

    ResourceManager or Context resources


The pool should:

- provide reusable frame/image/mask buffers
- reuse allocations between frames
- avoid unnecessary heap allocations during real-time rendering


Requirements:

- preserve Arc ownership model
- do not introduce unsafe code unless required
- do not complicate simple operations unnecessarily

==================================================
2. Executor Traversal Optimization
==================================================

Inspect the executor implementation.

Current graph execution likely walks:

    output node
        |
        v
    input nodes
        |
        v
    dependencies


Optimize only if needed.

Potential improvements:

- cache execution order after graph validation
- avoid repeated dependency traversal
- store a topological execution order


Example:

Instead of every frame:

    recursively discover:
        A -> B -> C -> D


Do once:

    validation phase:
        create execution order


Then every frame:

    execute cached order


Invalidate the cache when graph structure changes.

==================================================
3. Value Allocation Optimization
==================================================

Inspect how Values are created during execution.

Avoid unnecessary copies.

Preferred:

    Value::Frame(Arc<Frame>)

Avoid:

    clone entire pixel buffers


When possible:

- pass Arc references
- reuse existing buffers
- move ownership where appropriate


Do not optimize away clarity.

Verify:

- resources survive graph rebuilds
- resources are not recreated every render tick
- temporary allocations are not stored forever
